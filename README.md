# Foam Board Stacker (Demo)

iPhone-first, one-tap stacking game PWA featuring the Gilman Brothers foam board line. Plain HTML/JS + canvas 2D, offline service worker (`fbs-v1`).

- **Branding:** everything brand-related is in `config.js` (`BRAND_NAME`, logo paths, hosts). Logo files in `assets/` are the official PNGs from gilmanbrothers.com:
  - https://gilmanbrothers.com/wp-content/uploads/2024/02/gilman-brothers-logo-complete.png
  - https://gilmanbrothers.com/wp-content/uploads/2024/07/GilmanLogo3x6-900dpi.png
- **Products:** `products.js` is generated by `tools/build-products.py` from `tools/catalog-source.json` (site review). Names, taglines and descriptions are verbatim; each board's in-game trait is loosely based on a quoted catalog property.
- **Hosts:** Evan and Cyrus are neutral placeholder pixel characters (`sprites.js`); the site has no identified photos of either.
- **Tests:** `node tests/run.js` (Playwright WebKit iPhone 15 / iPhone SE + Chromium) against a local server on :8833.

Demo build, not an official Gilman Brothers app.
